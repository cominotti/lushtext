# Samples

This folder contains the canonical sample content used to demonstrate and
manually verify what LushText currently supports in user-facing workflows.

Guidelines for this folder:

- Keep samples focused on shipped behavior, not aspirational behavior.
- Prefer one canonical sample per feature area instead of many overlapping test
  files.
- Update the relevant sample in the same change whenever supported behavior for
  that feature area changes.

Current canonical samples:

- `markdown-test.md` — the canonical Markdown preview showcase, covering the
  Markdown-related features LushText currently renders natively.
