# Accessibility Surface Inventory

This inventory is the review checklist for the state-of-the-art GTK accessibility change. Each row records state extremes, required semantics, keyboard and announcement behavior, proof lanes, and current baseline status.

State keys:

- `No context`: surface is present with no file, workspace, result, note, or history data.
- `Populated`: representative real data is visible.
- `Dense`: long names, many rows, awkward paths, large counts, or unusual values are visible.
- `Constrained`: narrow/short windows, compact bottom sheets, large text, or clipped geometry are active.

Proof lane keys:

- `Widget`: fast widget/unit tests with GTK accessible properties but no live bridge.
- `AT-SPI`: live headless accessibility tree, focus, state, or text artifacts.
- `Keyboard`: keyboard-only workflow test or smoke action path.
- `Visual`: screenshot/geometry evidence for focus, contrast, scale, and readable layout.
- `Manual`: release-level Orca or normal-session verification for behavior not exposed by automation.
