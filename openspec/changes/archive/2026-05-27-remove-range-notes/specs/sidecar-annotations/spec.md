## REMOVED Requirements

### Requirement: Users can create and manage sidecar annotations on saved files
**Reason**: Range Notes are removed as a clean-break feature family.

### Requirement: Annotations persist independently from source file content
**Reason**: Annotation sidecar persistence is removed with the Range Notes feature.

### Requirement: Annotation anchors track edits while a file is open
**Reason**: Live range anchors and edit tracking are removed with the Range Notes feature.

### Requirement: Users can export annotations for review and handoff
**Reason**: Range-note export is removed with the Range Notes feature.

### Requirement: Annotation identity follows in-app renames and resets on Save As
**Reason**: Annotation sidecar identity and rename handling are removed with the Range Notes feature.

### Requirement: Empty annotation state removes its sidecar file
**Reason**: Annotation sidecar writes and deletes are removed with the Range Notes feature.

### Requirement: Range notes appear in the workspace-scoped notes browser
**Reason**: Range Notes are removed from the workspace-scoped notes browser.

### Requirement: Range-note browser entries use the native Adwaita sidebar rail
**Reason**: Range Note browser entries are removed from the application.

### Requirement: Range-note editor mode switching is layout-stable
**Reason**: The Range Note editor popup is removed from the application.
